# Project demo video

[Watch the narrated walkthrough](demo.mp4) · [English subtitles](demo.srt)

Length: approximately **2 minutes 3 seconds**. Format: **1920 × 1080, H.264 video with AAC audio**, approximately 3.7 MB.

The video uses actual captures of the current application, with English narration and captions. It is an edited walkthrough: screen changes and waiting periods are condensed, rather than presented as a continuous real-time recording.

The walkthrough covers:

- The original passenger interface, picture requests and microphone control.
- Explicit opt-in for Online mode and the Saaras, Groq, Sarvam and Bulbul pipeline.
- A Hindi hot-water request delivered to the crew in Japanese and English.
- A crew reply shown in Hindi, with a Bulbul speech sample.
- The Roman Hindi request “Mujhe rum aur whisky chahiye” arriving as **Other request**, with “I want rum and whiskey.” and the original words on the crew tablet.
- The fifteen-language picker and a Tamil meal-service announcement, including its bundled recorded audio.
- Switching back to the original Offline mode.

The request examples were entered through the running passenger app, and the crew responses and announcement were sent through the running crew console. No request state or translation was fabricated for the video. The demonstrated request entry is typed; microphone recording is described and its existing control is shown. English voice-over is synthesized narration, while the Hindi reply sample uses the configured Bulbul service and the Tamil announcement uses the project's recorded asset.

The public demo contains sample booking data and public example requests. Private phone entry links, QR access tokens and API credentials are excluded.

`docs/demo.mp4` is also copied to `apps/ife/public/demo.mp4`, so the app's **Recorded demo** control opens the current walkthrough. The historical short clip remains at `docs/demo-short.mp4`.
