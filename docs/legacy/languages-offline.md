# Languages: what is actually covered

_Generated by `npm run languages -w @hearme/hub` on 2026-10-24. Do not edit by hand._

HearMe does not have a list of "supported languages". Speech recognition, understanding a request, the screens a passenger reads, the replies they get back and reading those replies aloud are five separate pieces of work, and a language can be finished in some and unfinished in others. This file says which, for each one.

A "pack" language is one added as a data file (`packages/shared/src/i18n/packs/<code>.ts`) rather than written into every catalogue. It carries its own request vocabulary, its 105-string passenger path, all 11 verified replies and all 40 need labels, and falls back to a core language for the screens it has not translated — settings detail, the announcement list, and the safety briefing.

**Nothing here has been reviewed by a native speaker.** Every row says `non-native`, and that is the single biggest gap before a pilot. Care Mode wording and the safety briefing are deliberately *not* translated in any pack: they are the text a crew member acts on medically, so they need clinical and airline review in each language and until then they appear in the fallback language.

## Where each pack language’s words came from

- **Bengali** (বাংলা) — Written for the prototype by a non-native author who reads Bengali. Needs a native speaker’s review before any pilot. Spoken Bengali is weak: Whisper-small writes it in Devanagari and 42% of spoken requests were right first time.
- **Tamil** (தமிழ்) — Began as an offline NLLB-200 draft of the English catalogue, then corrected by hand — the machine draft had called a pillow “powder”, a blanket “cloth”, a soft drink “alcohol” and tissues “AIDS”. Needs a native speaker’s review before any pilot. Vocabulary began as an NLLB-200 machine draft and was corrected by hand; still needs a native speaker.
- **Punjabi** (ਪੰਜਾਬੀ) — Written for the prototype by a non-native author who reads Gurmukhi. Needs a native speaker’s review before any pilot. Not yet measured on speech. Untranslated screen text appears in Hindi.
- **Marathi** (मराठी) — Written for the prototype by a non-native author who reads Devanagari. Needs a native speaker’s review before any pilot. Not yet measured on speech. Untranslated screen text appears in Hindi.
- **Gujarati** (ગુજરાતી) — Written directly in Gujarati for the prototype by a non-native author, not translated from English or Hindi. Needs a native speaker’s review before any pilot. Not yet measured on speech. Untranslated screen text appears in Hindi.
- **Kannada** (ಕನ್ನಡ) — Written directly in Kannada for the prototype by a non-native author, not translated from English or Hindi. Needs a native speaker’s review before any pilot. Not yet measured on speech.
- **Malayalam** (മലയാളം) — Written directly in Malayalam for the prototype by a non-native author, not translated from English or Hindi. Needs a native speaker’s review before any pilot. Not yet measured on speech.
- **Odia** (ଓଡ଼ିଆ) — Written directly in Odia for the prototype by a non-native author, not translated from English or Hindi. Needs a native speaker’s review before any pilot. Whisper has no Odia: speech is transcribed as Hindi and moved into Odia letters, so spoken Odia is matched by sound. Typing works fully.
- **Telugu** (తెలుగు) — Written directly in Telugu for the prototype by a non-native author, not translated from English or Hindi. Needs a native speaker’s review before any pilot. Not yet measured on speech.

## Measured: the keyword matcher alone, on held-out sentences

Twelve requests per language, one phrasing each, written after the vocabulary was fixed and never used to tune it. Scored by the keyword matcher **with no embedding model and no trained classifier** — so these numbers reproduce on any laptop with `npm run languages -w @hearme/hub`, and they are a floor, not the headline. `npm run eval -w @hearme/hub` measures the full pipeline.

"Before" is the same sentences with the language packs switched off, which is what HearMe scored on these languages previously.

- The six core languages are unchanged: the packs added vocabulary, they did not disturb what was already there.
- Marathi starts higher than the other three without a pack because it is written in the same script as Hindi, so some Hindi keywords already matched it.
- **The pack languages’ numbers are optimistic.** Their vocabulary and these test sentences were written by the same author, so words overlap in a way they would not for a sentence from a real passenger. The six core languages do not have this problem. A native speaker writing a fresh set is the fix, and it has not been done.
- Two sentences still fail on keywords alone (Bengali and Punjabi, both "my body isn’t doing well", neither containing a catalogue word). They were left failing rather than adding those exact words, which would have tuned the vocabulary on the held-out set and made this whole table meaningless. Phrasings with no keyword are what the embedding model is for.

## What these numbers do not tell you

- **Nothing here involves a microphone.** These are typed sentences. Spoken accuracy needs Whisper, and is measured by `npm run eval -w @hearme/hub -- --speech` (synthetic voices) and the voice lab (real people).
- **Punjabi and Marathi speech is unmeasured.** Whisper lists both, but macOS has no `say` voice for either, so the synthetic-speech evaluation skips them and reports that it did. They need real speakers in the voice lab.
- **Bengali and Tamil speech is weak**, measured earlier at 42–50% of spoken requests right first time. Whisper-small hears these languages poorly; a larger speech model is the obvious next step.
- **No native-speaker review, anywhere.** See the table above.
