# HearMe

Existing product, extracted from the user-supplied jetro-hackathon-main.zip. Passenger phone app and seatback IFE communicate needs to a crew tablet through an offline cabin hub or browser simulation. Includes multilingual request templates, speech input, announcements, private requests, medical care, and accessibility preferences.

This change is a Japan Airlines-inspired UI redesign explicitly requested by the user. It preserves existing features and does not add an entertainment catalog, live flight data, or airline integration. Brand direction is supplied by the user; native and web layouts remain appropriate to their devices.
